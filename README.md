# OrbisUI

A portable, controller-first PlayStation 4 style home screen for Windows handhelds (built and tuned for the ASUS ROG Ally).

It is a personal project. It is a native WPF (.NET 10) shell with native DualShock 4 input (SDL3/HIDAPI over USB and Bluetooth). It brings together Steam, PC games and the PS1/PS2/PS3/PS4/PSP/Vita emulators in one console-style interface.
